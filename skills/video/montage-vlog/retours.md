# Journal de retours — exemple de format

Le vrai journal se tient dans `retours.local.md`, à côté de cette skill. Ce fichier-là
n'est pas versionné (voir `.gitignore`). On n'y copie pas de nom, d'e-mail, de lieu réel
ni de citation identifiable : ces détails restent locaux. Ici, seulement la forme.

## AAAA-MM-JJ — jour 1, destination exemple

- « Laisse les phrases se finir. » — négatif, coupe. Action : marge de 0,5 s après la
  dernière ponctuation, puis fondu audio.
- « La musique couvre la voix. » — négatif, mix. Action : baisser le lit et renforcer
  le ducking sur tous les passages parlés, pas seulement celui qui a été signalé.
- « Le rythme et les couleurs conviennent. » — positif, musique / étalonnage. Action :
  geler ces réglages comme « à conserver ».

Pour chaque ligne : citation (dans le fichier local seulement), positif ou négatif,
catégorie, action décidée, paramètre modifié (avant → après).
